# Benchmarks — AMD EPYC 7702 64-Core Processor, 64 threads

Raw output of `make bench`, pinned to one core (`taskset -c 2`), one run.
Ratios are stable to about 2% across repeats; the `-O1` sentinel column is the
least stable and is reproducible at 0.49–0.52.

```
cc (Ubuntu 13.3.0-6ubuntu2~24.04.1) 13.3.0
```

## Reproduce

```bash
cd bench
make
taskset -c 2 make bench     # or just: make bench
```

Every program measures the naive and the tuned version in the same process,
on the same data, and prints `same result: yes` after checking they agree.
A benchmark that does not verify its own answer is a benchmark that can lie.

## Reading it

This is not a table of tricks. It is the ladder, priced.

| Rung | Example | Measured | What it means |
|---|---|---|---|
| 1. Algorithm | `prefix.c` | **11,382x** | Complexity is the only rung with an order of magnitude in it |
| 3. Representation | `bitsort.c` | **48x**, 38 MB → 1.19 MB | The value as its own address: ordering for free |
| 3. Representation | `layout.c` | **3.6x**, 153 MB → 38 MB touched | The cache bills you per byte, not per type |
| 2/3. Identity | `rotate.c` | **960x** | Three reversals instead of n rotations |
| 5. Code tuning | `sentinel.c` | **1.4x at -O0, 0.5x at -O1, 1.0x at -O2** | The constant factors from 1990 have mostly expired |
| 5. Code tuning | `bits.c` | **1.0x for the 1983 bit trick**, 13x for the instruction | Your CPU already has the trick in silicon |

The bottom two rows are the point. The `x &= x - 1` trick from every bit-twiddling
page since 1983 is a **wash** against the obvious shift loop on this machine —
not because the trick is wrong, but because the loop is latency-bound and the
trick has a longer dependency chain, and because `popcnt` exists. Bentley's
code-tuning chapter was written on hardware that charged per instruction. This
one does not.

So the ladder is not weighted evenly, and that is the lesson worth carrying:

> Spend your cleverness at rung 1 and rung 3. At rung 5, measure first —
> the answer is often "no change", and occasionally "twice as slow".
